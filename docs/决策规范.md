## 1. 覆盖倍数口径（M23/M25 定稿）
【代码】data-layer.js coverageAt（返回比率，展示层用倍数风格）
【验收锚点】招行 2.83 倍（5.70/2.016）；移动 1.35 非吃老本（M25 大师自纠）
- **覆盖倍数 = EPS ÷ 每股派息**（>1 健康，<1=吃老本）
- 分红率 = 派息 ÷ EPS（另一指标，禁止互换表述）
- "吃老本"判据 = 派息 > EPS（分红率 >100%）
- 全站唯一口径，倍数风格展示（"利润是分红的 2.8 倍"），比率只作公式注脚

## 2. 报告期归组与归属财年对齐（M29/M30 定稿）
【代码】data-layer.js ttmDivsAt/ttmDivsAtMode（B主+A兜底）、coverageAt（归属财年）
【验收锚点】招行 6-24 TTM=2.016（5.48%）；7-10 无跳变；分位 100% 出现=真实低点信号
- 分红与 EPS 均按 REPORT_DATE 归属财年（分红 2024 财年÷EPS 2024 财年，到账年不影响）
- TTM = B 口径（最近完整财年归属分红合计）+ A 兜底（366 天滚动窗口，防御性保留）
- "最近完整财年" = 有年报(12-31)记录、财年 < 当前年份的最近一年
- 计入锚 = 有除息日（pending=false，A 股实施公告即定除息日）
- EPS 年度终值：年报优先，无年报财年跳过；负/零 EPS → null（数据不足宁可不说）

# 三档线机制（v1.9.13 溢价分位定线·2026-08-18 大师 5 轮定案）

## 定稿机理
**机会线 = 市场对"分红可持续增长"信心的定价**：分红 CAGR 主因、支付率刚性次因、波动第三。
线高=信心低（工行：分红 CAGR 0.7%），线低=信心高（移动：派息率承诺+确定性）。
（替代旧表述"市场要求回报率"）

## 计算机制（v2：溢价分位，2026-08-18 大师第5轮定案）
- 三档线 = 个股**近 3 年风险溢价分位**：溢价 = dy − 国债收益率（**历史国债序列**，每日对应当日）
  - 小仓=P75 / 加仓=P90 / 重仓=P95（溢价 pp 分位；触发比较 dy−国债_当日 ≥ 分位线，数学等价于 dy ≥ 分位+国债）
- **当日常数国债=白改**（2026-08-18 大师 A1 收回教训）：P90(dy−c)=P90(dy)−c 单调变换，线完全不变——必须历史序列
- 国债序列 v1 = 年度锚点插值近似（2010:4.0→2026:1.55，三重标注：近似·插值·正式源待接入 backlog 1 个月内）
- 触发判定等价性：dy ≥ p+国债 ⟺ dy−国债 ≥ p（卡面显示回算 dy 口径线）
- **季度重算固定**（两次之间不漂移；重算时 CHANGELOG 记线变化）；重算脚本 test/gen-tier-line-v2.js
- 行业线（BENCH）= 未入表股票兜底 + 卡面参考展示（"行业参考 X%"），不再做触发
- **近1年参考窗**（大师第4轮 A2）：溢价口径近1年 P90 小字参考，只展示不触发，防"线含过去时"

## 红线与标注
- **支付率 >90% 或 <20%**（近2财年）→ 分位线降级"仅参考"（兖矿类周期/人寿类低分红/五粮液 104%/双汇 98%）
- **K线源故障** → 股息率线暂替（pending），只展示不触发（移动 2026-08-18，多源重试待补）
- **漂移检测**（大师第5轮 A4）：连续 3 季累计下移 >0.8pp 触发警示（实测标定 2026-08-18：平均季差 0.14-0.24pp/最大 0.46-1.36pp，0.3pp×2 过严否决）
- 卡面语义行："线高=市场对其分红增长信心低"，非买卖建议

## 回测证据（溢价分位 v2）
- P75/P90/P95 全行业 3-5 年胜率 78% 合计（40 只×16 年，含分红口径）vs 股息率分位 79-81%——差异在 ±2.6% 标准误内（234-252 样本），**胜率持平+坐标正确=验收通过**
- consumer/insurer 小样本方向性恶化（3y -7pp/-13pp，34/22 次）→ **监控项**（下次回测复查，持续恶化需专项核查）
- 溢价分位的价值：剥离利率错配（工行 6.57→5.76 可达、平安 等待→小仓 修正），整体胜率持平
- 含分红=触发日（含）后首个除息日起的除息合计（未计再投/税费）
