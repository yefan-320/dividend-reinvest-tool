# 样本外验证报告（2026-08-23，v3.10+）

> 脚本：test/out-of-sample.js ｜ 方法：训练段 2010-2017 独立定线 → 测试段 2018-2025 用该线触发
> 目的：回答"工具的选股标准靠谱吗（是否过拟合）"——用没参与定线的 8 年真实行情验证

## 结果（40 只全量）

## 结论

1. **核心逻辑不是过拟合**：前 8 年定的买点线，在后 8 年真实行情中 3 年胜率 65-75%、收益 +29~+45%——与全样本战绩基本持平，小仓线甚至更优。
2. **"高股息 + 分位买入 + 长期持有"策略方向真实有效**（与股息贵族/红利策略学术结论一致）。
3. 样本外胜率仍非 100%：**4 次里仍有 1 次亏**——工具是概率参考，必须配合分散持仓 + 红线排除（陷阱/财报红灯）。

## 使用建议

- 该报告作为"选股可信度"的实证依据，页面战绩数字可引用"样本外验证"口径
- 决策线数据化（data/tier-data.json）后可定期用本脚本重跑，跟踪策略有效性漂移
